# AutoVitrine

Protótipo estático em HTML, CSS e JavaScript.

- `index.html`: catálogo de carros.
- `detalhes.html`: página simples de detalhes com uma foto, preço, ficha técnica e descrição.
- `styles.css`: estilos compartilhados pelas duas páginas.
- `script.js`: busca, filtros rápidos e favoritos do catálogo.

Abra `index.html` no navegador para visualizar o catálogo. O botão “Ver detalhes” abre a página de detalhes.

Os dados e imagens atuais são apenas exemplos visuais. Quando você começar o Django, poderá substituir os textos, imagens e links pelos dados do banco sem precisar refazer o layout.
